# 📋 Kanban Board

A modern and responsive Kanban Board application built using React JS.

This project helps users organize and manage their tasks by moving them between different stages in a simple and user-friendly interface.

---

## 🌐 Live Demo

👉 https://puratchidevi.github.io/Kanban-board/

---

## 📌 Project Overview

The main goal of this project is to create a simple task management board using React JS.

Users can:

* Create new tasks
* View tasks based on their status
* Move tasks between columns
* Delete tasks
* Manage tasks using drag and drop
